This site is built around one idea: **do all the heavy work once, at ingest time, and ship
nothing but static HTML and images.**

## The ingestion pipeline

Photos exported from Lightroom land in a staging folder, and a single command does the rest:

```bash
npm run ingest -- --location "RIAT, Fairford" --tags airshow
```

For every image the CLI:

1. reads EXIF with ExifTool — camera body, lens, focal length, aperture, shutter speed, ISO
2. generates AVIF and WebP variants at 640 / 1080 / 1920 / 3840 px with sharp
3. creates a ~400-byte blurred placeholder inlined as a `data:` URI (no Blurhash decoding JS)
4. uploads everything to Cloudflare R2 with immutable cache headers
5. writes a typed JSON content entry that Astro validates against a Zod schema

GPS tags are stripped from every published variant, and re-runs are idempotent — files are
tracked by content hash, and hand-edited titles or alt text survive re-ingestion.

## Why the site is fast

- **Static generation** — every page is plain HTML on a CDN; builds never touch image bytes
- **Justified gallery with zero JS** — flexbox with `flex-grow` proportional to each photo's
  aspect ratio produces even rows from mixed 3:2 / 2:3 / 16:9 frames
- **`<picture>` with AVIF → WebP** srcsets and explicit dimensions for zero layout shift
- **One small script** — the lightbox (`<dialog>` + View Transitions API) is the only
  JavaScript shipped on photo pages
